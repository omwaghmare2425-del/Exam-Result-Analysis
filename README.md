# Examination Result Processing and Analysis System

## 📌 Project Overview

The Examination Result Processing and Analysis System is a Python-based application designed to process student examination results from Excel files.

The system automatically validates, calculates, ranks and analyzes examination results.

---

## 🎯 Objectives

- Read student examination data from Excel.
- Validate student and marks information.
- Detect missing values.
- Detect invalid marks.
- Detect negative marks.
- Detect marks greater than maximum marks.
- Handle absent students.
- Detect duplicate student-subject records.
- Calculate subject-wise percentage.
- Calculate student total and percentage.
- Generate grades.
- Determine PASS/FAIL status.
- Calculate student ranks.
- Identify toppers.
- Perform class-level analysis.
- Perform subject-level analysis.
- Identify low-performing subjects.
- Generate charts.
- Export processed results into Excel.

---

## 🛠 Technologies Used

- Pandas
- NumPy
- OpenPyXL

- Streamlit
